# Barbarian Theme configuration

Barbarian Theme exposes a public CSS custom-property API. Application code and custom variants should override variables prefixed with `--barbarian-`.

Component files intentionally keep their implementation details private. Avoid overriding the older internal variables such as `--albero`, `--cuero`, `--sup-panel` or `--tinta`; they exist as compatibility aliases and may change internally.

## Core palette

| Token | Purpose |
| --- | --- |
| `--barbarian-primary` | Main brand/action color |
| `--barbarian-primary-rgb` | RGB channels used by Bootstrap utilities |
| `--barbarian-primary-light` | Light primary tone |
| `--barbarian-primary-dark` | Dark primary tone |
| `--barbarian-secondary` | Secondary color |
| `--barbarian-secondary-rgb` | Secondary RGB channels |
| `--barbarian-success` | Success color |
| `--barbarian-info` | Informational color |
| `--barbarian-warning` | Warning color |
| `--barbarian-danger` | Danger color |
| `--barbarian-bone` | Pale/high-contrast neutral |
| `--barbarian-leather` | Main leather tone |
| `--barbarian-leather-dark` | Dark leather tone |
| `--barbarian-fur` | Fur/nav/header dark tone |
| `--barbarian-ember` | Glow and focus accent |

## Textures

Textures are configurable too:

```css
--barbarian-texture-grain
--barbarian-texture-veins
--barbarian-texture-leather
--barbarian-texture-leather-dark
--barbarian-texture-fur
--barbarian-texture-fur-edge
```

The production CSS generated by esbuild inlines the default SVG textures as data URLs.

To create a completely flat version:

```css
:root {
  --barbarian-texture-grain: none;
  --barbarian-texture-veins: none;
  --barbarian-texture-leather: none;
  --barbarian-texture-leather-dark: none;
  --barbarian-texture-fur: none;
  --barbarian-texture-fur-edge: none;
}
```

## Creating an application-specific variant

A project can customize Barbarian Theme without modifying this repository:

```html
<link rel="stylesheet" href="bootstrap.min.css">
<link rel="stylesheet" href="barbarian-theme.min.css">
<link rel="stylesheet" href="my-barbarian-variant.css">
```

`my-barbarian-variant.css`:

```css
:root {
  --barbarian-primary: #7559a6;
  --barbarian-primary-rgb: 117, 89, 166;
  --barbarian-leather: #51405d;
  --barbarian-leather-dark: #2b2232;
  --barbarian-surface: #d5c9dc;
  --barbarian-surface-raised: #eee8f1;
  --barbarian-surface-raised-rgb: 238, 232, 241;
  --barbarian-heading: #49345a;
  --barbarian-accent: #694789;
  --barbarian-border: #765f82;
}
```

All Bootstrap components continue to consume the same component CSS. Only the token values change.

## Creating a built-in variant

Built-in variants live under:

```text
src/themes/
```

A variant should override public tokens rather than component selectors.

Example:

```css
[data-barbarian-variant="volcanic"] {
  --barbarian-primary: #d26231;
  --barbarian-primary-rgb: 210, 98, 49;
  --barbarian-ember: #ff9a3c;
  --barbarian-surface: #a77b62;
  --barbarian-heading: #5b2117;
}

[data-barbarian-variant="volcanic"][data-bs-theme="dark"],
[data-bs-theme="dark"] [data-barbarian-variant="volcanic"] {
  --barbarian-surface: #281916;
  --barbarian-heading: #f2b080;
}
```

Then import it from `src/barbarian-theme.css` and rebuild.

## Runtime API

The optional JavaScript bundle exposes `window.BarbarianTheme`.

```js
BarbarianTheme.init();

BarbarianTheme.setVariant('ice');
BarbarianTheme.setColorMode('dark');

BarbarianTheme.setColorMode('auto');
BarbarianTheme.toggleColorMode();
```

Built-in variants:

```text
desert
nordic
blood
ice
dark-kingdom
```

The selected variant is stored under `barbarian-variant`. The selected color mode is stored under `barbarian-color-mode`.

## Events

The JS helper dispatches:

```text
barbarian:themechange
barbarian:variantchange
```

The legacy `tema-cambiado` event is also emitted for compatibility with the original desert effect.

## Bootstrap bridge

The public tokens are mapped back into Bootstrap variables such as:

```css
--bs-primary
--bs-primary-rgb
--bs-secondary
--bs-body-bg
--bs-body-color
--bs-heading-color
--bs-border-color
--bs-border-radius
```

That bridge is what allows ordinary Bootstrap components and utility classes to follow the Barbarian configuration without changing their HTML.
